# Arena AI Android (v1.2)

独立封装的 LMSYS Arena (https://arena.ai) Android 客户端，内置大额号增强与自动化抽卡套件。

## 📥 APK 直接下载
- **最新安装包**: [Arena_AI.apk (237 KB)](Arena_AI.apk)

## ✨ 特性亮点
1. **轻量与原生性能**：全包仅 230KB，基于 Android 13/14+ 原生 WebView 与系统 Chrome 内核。
2. **免插件脚本注入**：内置 Arena Native Suite 增强脚本，支持自动化对战抽卡，默认提示词已更新为 `直接回复我1+1`。
3. **沉浸式深浅色适配**：深色模式顶部状态栏无缝融为一体，底部自动避让系统手势栏与键盘，告别遮挡。
4. **自适应官方双图标**：支持 Arena 官方白底与黑底双启动图标，并支持 Android 13+ Material You 动态主题变色。
